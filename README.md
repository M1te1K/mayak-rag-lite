# Маяк · RAG-lite

CLI-бот на Python для **варианта 1** тестового задания. Общие вопросы идут в LLM; вопросы по PDF - в локальный семантический поиск, затем в LLM для выбора доказательств. Ответ по документу содержит дословные цитаты, страницу и ID фрагмента. Если подтверждения нет: **В документе этого нет**.

## Установка и запуск

Нужны Git, Python 3.13 и интернет для установки, первой загрузки E5 и работы LLM. Пакет допускает Python 3.11-3.14; полный локальный запуск проверен на **macOS arm64 / Python 3.13.13**. На Linux / Python 3.13 GitHub Actions подтвердил установку по lock и 94 программных теста; E5 там не загружается. Команды ниже предназначены для macOS/Linux. Windows/PowerShell в этой работе не проверялись.

Модель поиска работает на CPU; GPU и отдельная векторная БД не нужны. Нужен процессор x86-64 или arm64, для которого доступна сборка PyTorch. Заложите несколько ГБ свободного диска на окружение и кэш, с запасом от 5 ГБ: проверенное macOS-окружение занимает около 1.1 ГБ, веса E5 - около 475 МБ; размер зависимостей на другой ОС может отличаться.

Репозиторий **приватный**: владелец должен предоставить доступ проверяющему. Для `git clone` войдите в GitHub через GitHub Desktop/настроенный credential helper либо используйте SSH с уже настроенным ключом. Пароль аккаунта GitHub не подходит для HTTPS Git; не вставляйте токены в URL.

```bash
git clone https://github.com/M1te1K/mayak-rag-lite.git
cd mayak-rag-lite
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -c requirements.lock.txt '.[dev]'
test -e .env || cp .env.example .env
```

Откройте `.env` в локальном редакторе и заполните `GROQ_API_KEY`. Ключ не нужно присылать в чат или помещать в Git. Приведённая команда создаёт `.env` только при его отсутствии. Существующие настройки сохраняются.

```bash
python -m mayak --check
python -m mayak
```

`--check` действительно извлекает PDF, строит embeddings и индекс, но не вызывает LLM. После установки доступна и команда `mayak`. `requirements.lock.txt` фиксирует фактически проверенные версии; без `-c` установщик выберет совместимые версии из диапазонов `pyproject.toml`. Запускайте из корня проекта: относительные пути считаются от текущей папки. Другой документ: `python -m mayak --pdf '/полный/путь/document.pdf'`.

Первый запуск скачивает публичную `intfloat/multilingual-e5-small` с Hugging Face в `.cache/models` без ключа, затем выполняет вычисления на CPU. Нужны интернет и несколько минут (при медленной загрузке Hugging Face можно задать `HF_HUB_DISABLE_XET=1`); веса занимают около 0.5 ГБ, окружение с PyTorch - ещё несколько ГБ. После загрузки повторный запуск использует кэш; для полностью локального поиска можно задать `HF_HUB_OFFLINE=1`. LLM по-прежнему требует интернета. Embeddings бесплатны и вычисляются на компьютере, отдельного сервера БД нет.

## Бесплатный API

По умолчанию используется **Groq Free Plan**, точный ID `openai/gpt-oss-120b`. Зарегистрируйтесь в [Groq Console](https://console.groq.com/keys), создайте API key и вставьте только его значение в локальный `.env`. Оставьте аккаунт на Free Plan, без перехода на Developer. Программа не меняет тариф аккаунта и не может установить его по ключу: бесплатность Groq зависит от настроек вашего аккаунта. См. [официальное описание тарифа](https://console.groq.com/docs/billing-faqs).

Запасной провайдер включается **вручную**, одновременно измените три строки:

```dotenv
LLM_PROVIDER=openrouter
LLM_MODEL=google/gemma-4-31b-it:free
OPENROUTER_API_KEY=ваш_локальный_ключ
```

Создайте ключ в [OpenRouter Settings](https://openrouter.ai/settings/keys). Покупать кредиты не требуется для доступных бесплатных моделей. `:free` обязательно. Клиент ограничивает стоимость prompt/completion нулём, отключает fallback и не отправляет массив запасных моделей, плагины или веб-инструменты. Если бесплатный endpoint недоступен, будет ошибка, без платного переключения. Настройки приватности аккаунта могут ограничивать доступные endpoints; не отправляйте конфиденциальные документы без изучения политики выбранного провайдера.

Проверено по официальным источникам **14 октября 2026 года**:

| Провайдер | Модель | Публичные ограничения |
|---|---|---|
| Groq Free Plan | `openai/gpt-oss-120b` | 30 запросов/мин, 1000/сутки, 8000 токенов/мин, 200000/сутки |
| OpenRouter без покупки кредитов | `google/gemma-4-31b-it:free` | 20 запросов/мин, 50/сутки суммарно по бесплатным моделям |

Это опубликованные ориентиры, **не гарантированные квоты вашего ключа**. Groq: [модели](https://console.groq.com/docs/models), [точные ограничения аккаунта](https://console.groq.com/docs/rate-limits). OpenRouter: [каталог API](https://openrouter.ai/api/v1/models), [официальное подтверждение 50/20](https://openrouter.ai/blog/tutorials/kilo-code-openrouter/), [лимиты и счётчик ключа](https://openrouter.ai/docs/api_reference/limits). Смена бесплатной модели не увеличивает дневную квоту. Groq проверен настоящими запросами 15 октября 2026 года; результат независимого и повторного прогонов разделён в [протоколе](docs/VALIDATION.md). OpenRouter проверен только программно, без авторизованного вызова. Тариф Groq по ключу не определялся.

Groq поддерживает [strict JSON Schema](https://console.groq.com/docs/structured-outputs) для GPT-OSS 120B: режим `auto` отправляет `response_format=json_schema`, `strict=true`. В каталоге бесплатной Gemma указана `response_format`, но нет `structured_outputs`; строгая схема для неё не подтверждена. Поэтому OpenRouter `auto` просит JSON текстовой инструкцией и всегда валидирует его через Pydantic. Невалидный JSON означает недоступность сервиса, а не отсутствие сведений в PDF. [Поддержка схем зависит от endpoint](https://openrouter.ai/docs/guides/features/structured-outputs).

Обычный общий вопрос - один HTTP-запрос. Распознанный запрос текущего курса или времени получает явное ограничение без обращения к LLM. Документный вопрос - до четырёх: выбор цитат и проверка, при необходимости повтор с расширенной выборкой. Отказ без цитат обычно требует одного-двух запросов. Нет автоматических HTTP-повторов: 429 учитывает `Retry-After` (секунды или HTTP-date), до срока блокирует новые API-запросы; без заголовка пауза 60 секунд. При таймауте, неверном ключе, сетевой ошибке, 429, 5xx или некорректном ответе бот пишет **Сервис временно недоступен**, остаётся в цикле и принимает `/help`, `/reset`, новые вопросы.

## Актуальные данные и заглушки

В этой версии нет часов, котировок и веб-поиска. Явные запросы вроде «какой курс доллара», «какое время в Японии» и короткие продолжения «а евро?», «а в Китае?» программно получают объяснение этого ограничения. Предполагаемые актуальные числа из LLM не запрашиваются и не сохраняются в истории. `/reset` сбрасывает и эту тему; новый статический вопрос переключает её. Обычные определения, числа и объяснения («8 битов в байте», «что означает курс валют», разница UTC+3/UTC+9) продолжают идти в LLM.

Системная инструкция дополнительно запрещает выдавать устаревшие сведения, придуманные значения и шаблонные заглушки за текущие факты. Нераскрытые маркеры вроде `[текущее время]` и `{{current_rate}}` вне примеров кода отклоняются как некорректный ответ API и не попадают в историю. Это узкая программная защита известных формулировок, а не универсальный классификатор всех актуальных вопросов. Другие перефразирования, новости и погода зависят от соблюдения моделью инструкции; актуальность произвольного ответа не гарантируется.

## Команды и область вопроса

- `/ask <вопрос>` - общая LLM, без доступа к PDF.
- `/doc <вопрос>` - только выбранный PDF.
- `по документу: ...`, `согласно документу: ...`, `в документе: ...` - явный документный режим.
- `в общем: ...`, `общий вопрос: ...`, `из общих знаний: ...` - общий режим.
- Обычное сообщение продолжает последний выбранный режим и учитывает ограниченную историю. Приветствие открывает общий режим.
- Если режима ещё нет и вопрос неоднозначен, бот уточняет область. Ответ «по документу» / «общий» применяет её к сохранённому вопросу.
- `/reset` удаляет историю, тему, режим и незавершённое уточнение. Индекс PDF остаётся.
- `/help`, `/exit`; Ctrl-D и Ctrl-C также завершают CLI.

Пример диалога (сокращённая иллюстрация; фактический повторный прогон хранится в `docs/review_live_results.json`):

```text
Вы> /ask Что такое RAG?
Бот> RAG дополняет запрос к языковой модели найденными фрагментами документов.
Вы> /doc Сколько стоит тариф Старт?
Бот> «Тариф «Старт» стоит 390 рублей в месяц за команду.»
Источник: mayak-demo.pdf, стр. 1, [p1-fd261195eee7]
Вы> а сколько сотрудников туда входит?
Бот> «В него входят 3 сотрудника и 200 заявок в месяц.»
Источник: mayak-demo.pdf, стр. 1, [p1-fd261195eee7]
Вы> /doc Кто владелец компании?
Бот> В документе этого нет
Вы> /reset
Бот> История очищена. Выберите /doc или /ask для нового вопроса.
Вы> а сколько это стоит?
Бот> Это вопрос по документу или общий? Напишите «по документу» или «общий».
```

Точный ответ и выбор цитаты зависят от модели; проверяйте её командой ниже.

## Как работает поиск и проверка

1. `pypdf` извлекает текст отдельно для каждой страницы. Отсутствующий, повреждённый, зашифрованный PDF и PDF без текста дают понятную ошибку запуска. Даже одна страница без текста останавливает загрузку: бот не выдаёт ограничение извлечения за отсутствие ответа. OCR не реализован.
2. Чанки строятся по **токенизатору E5** с небольшим перекрытием, сохраняют точные подстроки страниц, имя файла, страницу и стабильный ID (хеш PDF + положение + текст). Фрагменты не смешивают страницы. После разбиения проверяется **каждый** чанк: он обязан целиком помещаться в `CONTEXT_MAX_CHARS`. Иначе запуск завершается понятной ошибкой до диалога и вызовов LLM.
3. [Multilingual E5 small](https://huggingface.co/intfloat/multilingual-e5-small) поддерживает русский язык и асимметричный поиск. Запросы получают `query: `, фрагменты `passage: `, embeddings нормализуются. Вход ограничен 512 токенами; для чанков учитываются префикс и специальные токены, для длинного вопроса применяется обрезка модели. Поиск - скалярное произведение нормализованных векторов NumPy. Высокий score не доказывает наличия ответа.
4. В LLM передаются top-3 фрагмента в пределах 4800 символов и ограниченная история. При нехватке доказательств выборка расширяется до 6 фрагментов с соседями на той же странице. Документ целиком в каждый запрос не добавляется. Небольшой PDF может целиком поместиться в расширенную выборку. Если совокупный бюджет оставил часть выбранных кандидатов непроверенной, отказ об отсутствии факта не выдаётся: бот сообщает о техническом ограничении контекста. Это же относится к пустой выдаче поиска.
5. Модель возвращает `answer`, `has_evidence`, `source_chunk_ids`, `quotes`. Python проверяет типы, допустимые ID, совпадение списка источников и наличие каждой цитаты в переданных текстах (пробелы нормализуются). Свободный `answer` **не показывается**: пользователь получает только исходные цитаты и метаданные источников. Это исключает добавление в ответ вымышленных цен или дат свободной генерацией.
6. Второй LLM-запрос проверяет соответствие цитат вопросу, полноту и отсутствие управляющих команд. Он не получает свободно сгенерированный ответ. Если подтверждения нет, расширение не помогло и выбранные кандидаты проверены без технического пропуска - точный отказ. Ни история, ни команды внутри PDF не являются источником новых фактов. В документном режиме нет переключения к общим знаниям.

Проверка цитат детерминирована, но **семантическая проверка моделью не даёт математической гарантии**: возможны нерелевантная цитата, ложный отказ или неудачное разрешение местоимения. Дословный режим намеренно консервативен: расчёты и сложные выводы без прямого факта в PDF могут получить отказ. Реальная модель требует отдельной оценки; подмена клиента проверяет программные правила, а не качество русского языка или защиты от всех атак.

Индекс хранится в памяти и строится заново при каждом запуске, поэтому старые векторы не переживают изменение PDF/настроек. Кэшируются только веса модели. После изменения PDF во время работы перезапустите процесс.

## Все настройки `.env`

Переменные процесса имеют приоритет над `.env`. Лишние переменные не используются. Адреса API заданы в коде; ключи не отправляются произвольному хосту.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_PROVIDER` | `groq` | `groq` / `openrouter`, ручной выбор |
| `LLM_MODEL` | модель выбранного провайдера | Разрешены только два точных ID, приведённых выше |
| `GROQ_API_KEY` | пусто | Локальный ключ Groq |
| `OPENROUTER_API_KEY` | пусто | Локальный ключ OpenRouter |
| `LLM_JSON_MODE` | `auto` | `auto`, `schema` (только Groq), `prompt` |
| `LLM_TIMEOUT_SECONDS` | `30` | HTTP timeout, 1..120 секунд на сетевую операцию |
| `LLM_MAX_TOKENS` | `1200` | Лимит completion, 128..4096; Groq включает reasoning, effort=`low` |
| `PDF_PATH` | `output/pdf/mayak-demo.pdf` | Единственный источник знаний |
| `EMBEDDING_MODEL` | `intfloat/multilingual-e5-small` | В этой версии разрешена только проверенная модель |
| `MODEL_CACHE_DIR` | `.cache/models` | Локальный кэш весов |
| `CHUNK_TOKENS` | `220` | Размер чанка, 32..480 токенов, затем фактическая проверка окна |
| `CHUNK_OVERLAP` | `32` | Перекрытие, от 0 до размера чанка минус 1 |
| `RETRIEVAL_TOP_K` | `3` | Первая выборка |
| `RETRIEVAL_EXPANDED_K` | `6` | Расширенная выборка, TOP_K..12 |
| `CONTEXT_MAX_CHARS` | `4800` | 1000..12000 символов; каждый чанк должен помещаться целиком, иначе ошибка запуска |
| `HISTORY_MAX_TURNS` | `6` | Число завершённых пар вопрос-ответ, 1..20 |
| `HISTORY_MAX_CHARS` | `4000` | Общий размер истории, 500..10000 символов |
| `INPUT_MAX_CHARS` | `2000` | Максимальный вопрос, 50..8000 символов |
| `LOG_PATH` | `logs/bot.jsonl` | JSON Lines, ротация по 5 МБ, 2 копии |
| `CLI_USER_ID` | `cli-local` | Постоянный user_id для CLI |

История существует только в памяти процесса, при превышении бюджета удаляются самые старые полные пары. Если одна последняя пара превышает весь бюджет, она обрезается, а режим сохраняется. Общий и документный режимы получают историю своей области; `/reset` удаляет оба. При ошибке API режим сохраняется для повторного вопроса, неуспешная пара в историю не добавляется. `/reset` очищает диалоговую память, но аудиторские логи сохраняются.

## Логи

`logs/bot.jsonl`: `time` (UTC ISO 8601), `user_id`, `event`; в `request/response` - запрос и ответ. **Все** события одного запроса (включая поиск, расширение, LLM, цитаты и ошибки) несут один UUID `turn_id`, изолированный через `ContextVar`. У разных запросов ID различаются даже при общем файле и одинаковом user_id. Вне обработки запроса `scope=session`, `turn_id=null`; внутри `scope=request`. В `tool_call` - `local_search`, `expand_search`, `llm`, `reset_history`. Ошибки содержат безопасный код, без тела HTTP-ошибки/заголовков. События `retrieved`, `passed`, `cited` содержат ID, страницы, текст, scores и источник. `passed` содержит номер попытки, `cited` - подтверждённые цитаты. `tool_result` и `llm_usage` содержат только разрешённые числовые лимиты и расход токенов, без исходных HTTP-заголовков. `capability_limit` отмечает отсутствие инструментов актуальных данных.

Ключ активного провайдера, стандартные префиксы ключей и Bearer-значения редактируются даже внутри текста пользователя/чанка. `.env`, логи, кэши, окружения и временные файлы исключены из Git. Логи содержат вопросы и текст документа: это локальные данные, их не следует публиковать. Для просмотра: `tail -n 12 logs/bot.jsonl`.

python -m pytest -q -m 'not integration'

Автотесты используют `httpx.MockTransport` и подмену LLM: общие вопросы, факт и перефразирование, отказ, injection, уточнение и reset, расширение поиска, вымышленные источники/цитаты, семантический отказ, таймаут, ключ, 429/Retry-After, 5xx, некорректный JSON и отсутствие секретов в логах. Интеграционный локальный тест использует настоящую E5 и семь русских контрольных вопросов. Тесты не расходуют LLM-квоту. Повторная локальная проверка 15 октября: **98 тестов** (94 программных и 4 с настоящей E5). Есть отдельные регрессии обоих несовместимых бюджетов, точной границы, технически пустого/неполного контекста, актуальных вопросов, заглушек, истории и сквозного `turn_id`, в том числе при конкурентном журналировании. Настоящий поиск: 5/7 в top-3, 7/7 с расширением. Реальная независимая проверка Groq дала 3/3; новый последовательный прогон дал **15/15** (15 HTTP 200); его границы описаны в протоколе. OpenRouter не проверялся живыми запросами.

`live_check.py` выполняет сценарии последовательно, оценивает следующий расход токенов и при нехватке бюджета ждёт по фактическим числовым заголовкам провайдера. Оценка приблизительна; при любой ошибке API, включая 429, прогон прекращается без повтора. Режим `--review` ограничивает историю тестовой сессии тремя парами и 1200 символами, не меняя `.env`. Проверки текущего курса/времени проходят программным маршрутом без API; остальные вопросы используют настоящую модель. Совпадение ожидаемой подстроки в smoke test дополняется ручной проверкой смысла, но не является общей гарантией качества.

Для проверки изменяемого исходного кода после установки используйте `PYTHONPATH=src python -m pytest ...` или повторите установку. Команды без `PYTHONPATH` проверяют установленную копию пакета.

PDF: `output/pdf/mayak-demo.pdf`; исходник: `data/mayak-demo.txt`; контрольные вопросы: `data/evaluation.json`. Все факты вымышлены. PDF задания - источник требований, он не включён в базу знаний и не копируется в репозиторий. Воспроизводимое создание PDF со встроенным DejaVu Sans:

```bash
python scripts/build_demo_pdf.py
```

Встроенный шрифт и его лицензия хранятся в `assets/`. Итоги фактически выполненных проверок: [docs/VALIDATION.md](docs/VALIDATION.md). Инструкция защиты архитектуры: [docs/DEFENSE.md](docs/DEFENSE.md). Готовый текст сдачи: [docs/SUBMISSION.md](docs/SUBMISSION.md).

## Если запуск не получается

| Симптом | Что проверить |
|---|---|
| `git clone`: Repository not found / Authentication failed | Репозиторий приватный: проверьте доступ своего GitHub-аккаунта и вход через credential helper или GitHub Desktop |
| `No matching distribution found` при установке | Используйте Python 3.13, активируйте `.venv`, проверьте интернет и доступность пакетов для своей ОС/архитектуры; lock проверен на macOS arm64 |
| `No module named mayak` | Запустите установку из корня проекта в том же `.venv`, из которого вызываете Python |
| Не удалось загрузить модель поиска | При первой загрузке нужен Hugging Face; проверьте сеть, свободный диск и `MODEL_CACHE_DIR`. `HF_HUB_OFFLINE=1` работает только с уже загруженными весами |
| Нет PDF / скан без текста / зашифрованный PDF | Проверьте `PDF_PATH` или `--pdf`, права чтения и текстовый слой на всех страницах; OCR отсутствует |
| Ошибка `CONTEXT_MAX_CHARS` / техническое ограничение контекста | Верните значения из `.env.example` либо увеличьте бюджет/уменьшите `CHUNK_TOKENS`, затем перезапустите CLI |
| `Сервис временно недоступен` | Проверьте ключ выбранного провайдера, точный ID модели, сеть и безопасный код `error` в `logs/bot.jsonl`; ключ не выводите. При 429 дождитесь `Retry-After` или восстановления квоты, при 401 замените ключ локально |
| Ошибка доступа к файлам | Проверьте права записи `logs/` и `.cache/` и свободный диск; запуск с `sudo` не нужен |

Для своего PDF запускайте из корня клона: `python -m mayak --pdf '/путь/к/вашему.pdf' --check`, затем ту же команду без `--check`. При смене PDF перезапускайте процесс. В документном режиме выбранные фрагменты и история вопроса передаются внешнему LLM-провайдеру; сами embeddings вычисляются локально.

## Структура и публикация

```text
src/mayak/cli.py       терминальный ввод/вывод, сборка приложения
src/mayak/bot.py       команды, область вопроса, обработка ошибок
src/mayak/config.py    .env, проверка настроек и разрешённых моделей
src/mayak/llm.py       HTTP API, JSON Schema / JSON, 429 и ошибки
src/mayak/pdf.py       извлечение страниц, чанки, стабильные ID
src/mayak/search.py    E5, cosine ranking, соседи, бюджет контекста
src/mayak/answer.py    выбор цитат, валидация, проверка, вывод
src/mayak/history.py   ограниченная история и reset
src/mayak/general.py   ограничение актуальных данных и проверка заглушек
src/mayak/audit.py     JSONL, ротация, удаление секретов
```

`Bot` не зависит от терминала: Telegram позже сможет вызывать `handle()` у отдельного экземпляра на пользователя. Пока один процесс CLI - одна сессия. Веб-поиск, Telegram, Docker и деплой в эту версию не входят.

Репозиторий: [M1te1K/mayak-rag-lite](https://github.com/M1te1K/mayak-rag-lite), **private**. CI в `.github/workflows/tests.yml` выполняет Ruff, проверку форматирования, `pip check` и программные тесты без ключа и без загрузки embeddings. Фактический результат запуска проверяйте на вкладке [Actions](https://github.com/M1te1K/mayak-rag-lite/actions) и в протоколе проверок.

В Git включены исходники, тесты, скрипты, настройки CI, `pyproject.toml`, lock-файл, документация, вымышленный PDF с исходным текстом и DejaVu Sans с лицензией. `.env`, сырые журналы, кэши, виртуальные окружения, временные результаты, локальные `PROJECT_BRIEF.md` и `PROMPT_FOR_NEW_CHAT.md` исключены через `.gitignore`. Лицензия проекта отдельно не назначена; условия стороннего шрифта сохранены в `assets/LICENSE_DEJAVU`.
