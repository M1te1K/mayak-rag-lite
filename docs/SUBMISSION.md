# Текст сдачи

Выбрал вариант 1 (RAG-lite), потому что поиск по локальному PDF позволяет показать интеграцию LLM, проверяемые источники и корректный отказ на вопрос без подтверждения.

Репозиторий: [M1te1K/mayak-rag-lite](https://github.com/M1te1K/mayak-rag-lite), **приватный**; для проверки нужен доступ от владельца. CLI работает локально по README, отдельного хостинга нет.

После аудита исправлены защита известных запросов актуальных котировок/времени и заглушек, технические отказы из-за бюджета контекста, сквозная связь событий журналов. Реализованы общий и документный режимы, локальные многоязычные embeddings, сохранение страниц и источников, проверка цитат и достаточности сведений, история и `/reset`, JSONL-логи и обработка ошибок API. Есть демонстрационный PDF с исходником, автоматические проверки, README и скрипт реального smoke test.

Фактическое время первоначальной реализации 14 октября до завершения её проверок: **18 мин 58 с** (14.10.2026, **20:55:48 - 21:14:46 МСК**). Начало и конец зафиксированы инструментом времени на этапе реализации. Предварительное исследование выполнено раньше, его продолжительность не измерялась. Аудит, исправления и публикация в этот интервал не входят; общее время проекта не измерено. Время ожидания загрузок включено в указанный интервал, время ручной работы пользователя не заявляется.

Самое сложное в первоначальной реализации - отделить похожий фрагмент от достаточного доказательства и не принять валидный JSON/высокий score за правильный ответ. Поэтому бот проверяет реальные цитаты в Python, дополнительно проверяет их достаточность через LLM и показывает исходный текст вместо свободной генерации.

Что улучшить: оценить настоящую модель на более широком наборе вопросов, добавить OCR и более точную обработку таблиц, лучше разрешать уточнения, при расширении объёма добавить Telegram и инкрементальный индекс для нескольких документов.

Текущий статус после независимого аудита 15 октября: **98 тестов** прошли (94 программных + 4 с настоящими локальными embeddings), Ruff и pip check без ошибок. Поиск на семи русских вопросах: 5/7 в первой выборке и 7/7 после расширения. Независимый живой Groq-прогон до исправлений дал 3/3; отдельный новый последовательный контроль после исправлений дал **15/15** шагов, 15 HTTP 200, без 429. В четырёх вопросах актуальности и двух шагах reset/уточнения API не вызывался; остальные шаги использовали настоящую модель. OpenRouter проверен только программно. Настройки и ключ пользователя сохранены; тариф аккаунта не определялся и не менялся. Подробности: `docs/VALIDATION.md`.
