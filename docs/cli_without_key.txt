Загружаю PDF и локальную модель поиска. Первая загрузка требует интернета.
Готово: 6 фрагментов, groq / openai/gpt-oss-120b
Ключ API не задан. Добавьте его локально в .env и перезапустите бота.
/doc <вопрос> - ответ только по PDF с цитатами и источниками
/ask <вопрос> - общий вопрос через LLM
/reset - очистить историю, тему и режим; PDF останется доступен
/help - эта справка
/exit - выход
Можно написать «по документу: ...» или «в общем: ...».
После выбора режима обычные сообщения продолжают его до /reset или смены команды.

Вы> Бот> Сервис временно недоступен
